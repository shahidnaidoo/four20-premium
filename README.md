# Four20 premium neon preview

Responsive brand and venue showcase for Four20 Cannabis Lounge & Store, East London. Near-black palette, violet and lime neon lighting, sequential SVG cannabis leaf illumination, subtle flicker and ambient movement, scroll reveals, highlighted text tabs, no arrows or emojis.

Static HTML/CSS/JS. No dependencies or build command. Vercel: Other framework, project root as output.

The wide lounge image is an AI-assisted artistic retouch of supplied venue photography. The cannabis still life is generated editorial imagery, not actual inventory. Original photography remains available in the eight-image full-frame photo journal. Address and hours follow supplied artwork; confirm before official launch. No official social handle was reliably resolved and no contacts, products, prices or reviews were invented. No checkout, ordering, payment or membership processing.

Motion honors reduced-motion preferences. Gallery uses a native modal with text controls and supports Escape. Source checks validate anchors, assets, unique IDs, no arrow glyphs, no emoji and no cover cropping.
